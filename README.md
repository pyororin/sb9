# sb9

「ユーザー向け通知」のデスクトップ通知モックアップ(HTML 単体)です。

- デモ: https://pyororin.github.io/sb9/mock/user/notice.html

## ステータス

モックのみの**実験・デモ用**リポジトリです。バックエンドや実際の AI 機能は一切なく、画面上の動きだけを再現しています。コミット履歴には「第9回 生成AIコンテストのユーザー向けのモックページ」との記載があります。

## 内容

背景にデスクトップ画像を敷き、画面右端から 3 段階の通知カードがスライドインする様子を再現します。

1. 通知エリアにマウスを乗せると 1 つ目のカード(困りごとへの気づき、類似事例の提示)が表示される
2. 3 秒後に 2 つ目のカード(関係者との調整提案と「調整する」ボタン)が表示される
3. 「調整する」ボタンを押すと 3 つ目のカード(ミーティング調整完了の通知)が表示される

通知の文言はすべて固定のダミーで、ボタン以外の操作や外部通信はありません。

## 技術スタック

- HTML / CSS / JavaScript(フレームワーク・ビルドなし)
- GitHub Pages で公開

## 使い方

ビルドは不要です。`mock/user/notice.html` をブラウザで開くか、上記のデモ URL にアクセスしてください。

## 構成

```
mock/user/
  notice.html        通知モック本体(CSS / JS を含む単一ファイル)
  user-desktop.jpg   背景のデスクトップ画像
  assistant.png      通知のアバター画像
```

## 注意事項

- 表示内容はデモ用のフィクションであり、実在のサービスや人物とは関係ありません。
- ライセンスは未設定です。
